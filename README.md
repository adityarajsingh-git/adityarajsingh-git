#### 🔨 Building in public

- **J.A.R.V.I.S** — local multi-provider AI assistant platform. Three interfaces (web HUD, terminal TUI, ambient mode) on one **zero-dependency Node.js** core. OpenAI-compatible router over three upstreams with priority routing, health polling, automatic failover, SSE streaming and persona-injection middleware. Canvas 3D particle hologram, Hinglish voice input, neural TTS.
- **[StudyNotion v2](https://github.com/adityarajsingh-git/studynotion-v2)** — solo ground-up rebuild of a team-of-four course project. Instructor course builder with draft/publish, lesson CRUD with validated reordering, per-resource ownership checks. **229 automated tests**; ran a security review of my own code and fixed four issues (ReDoS in search, enrolled-student ID leak, defaulting JWT secret, missing rate limiting) — each guarded by a regression test.
- **[DualMind](https://github.com/adityarajsingh-git/dualmind-chatbot)** — dual-mode chatbot (Recruitment Assistant + Employee Help Desk) with a client-side **RAG** pipeline: scored retrieval picks the top-5 knowledge-base entries, then Claude or Gemini answers only from those excerpts, with citations. Bring-your-own-key; falls back to a rule engine on any failure.
- **AI-132 — Jira-to-PR Agent Cockpit** *(internal)* — turns Jira tickets into code via headless Claude Code CLI sessions against local repos, then drives Bitbucket PRs and Jenkins builds from one screen. Designed its multi-root project resolution; extended it to wire a whole journey — backend, frontend, branches — from one task + a Figma link. Controllable from a phone over Telegram.
- **[Portfolio](https://github.com/adityarajsingh-git/portfolio)** — [this site](https://adityarajsingh-dev.netlify.app). AMOLED dark/light themes, scroll-driven CSS 3D, zero libraries.
